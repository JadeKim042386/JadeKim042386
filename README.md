## 📌 Featured — Context Graph

<div align="center">
  <a href="https://github.com/JadeKim042386/context-graph">
    <img src="https://raw.githubusercontent.com/JadeKim042386/context-graph/main/assets/demo.gif" width="100%" alt="Ask a question in Claude Code, and the answer comes back as the statement itself with the file and line it sits on" />
  </a>
</div>

<table width="100%">
  <tr>
    <td width="60%" valign="top">
      <p>A <b>Claude Code plugin</b> that turns the notes you already write into a map you can
      ask. An answer is <b>the statement itself, with the file and line it sits on</b> — not a
      summary, and not a whole file dumped into context.</p>
      <ul>
        <li>🧠 <b>No language model in the build.</b> It copies the structure you wrote by hand
        — <code>## Relations</code>, <code>- supersedes [[...]]</code> — so nothing is guessed</li>
        <li>⚡ <b>0.1 s</b> to rebuild ~180 documents, byte-identical every run</li>
        <li>🔗 Walks the lineage of a decision: which one replaced which, in order</li>
        <li>🔒 100% local, Python standard library only, MIT</li>
      </ul>
      <p>
