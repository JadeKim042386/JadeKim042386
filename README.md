### [Context Graph](https://github.com/JadeKim042386/context-graph) — ask your notes, get the line

<div align="center">
  <a href="https://github.com/JadeKim042386/context-graph">
    <img src="https://raw.githubusercontent.com/JadeKim042386/context-graph/main/assets/demo.gif" width="100%" alt="A question asked in Claude Code, the statement lighting up on the map, and the answer coming back with its file and line" />
  </a>
</div>

<table width="100%">
  <tr>
    <td width="62%" valign="top">
      <p>A <b>Claude Code plugin</b>. Notes pile up, and a single check turns into reading a whole
      file — 289,000 characters to catch up on one thread, on the set I built it against. This
      turns that around: you ask in your own words and get back <b>the statement itself, with the
      file and line it sits on</b>.</p>
      <ul>
        <li>🧠 <b>No language model in the build.</b> The relations are already written by hand —
          <code>- supersedes [[...]]</code> — so they are copied, never guessed</li>
        <li>⚡ <b>0.11 s</b> to rebuild 182 documents, byte-identical on every run</li>
        <li>🔗 Walks the lineage of a decision: which one replaced which, in order</li>
        <li>🩺 Every build scores itself and checks sampled answers against the source line</li>
        <li>🔒 100% local · Python standard library only · MIT</li>
      </ul>
    </td>
